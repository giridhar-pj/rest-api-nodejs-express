# Codveda Full-Stack Internship - Level 1, Task 2: Simple REST API

A REST API built with Node.js and Express, supporting full CRUD operations on a products resource.

## Tech Stack
- Node.js
- Express.js

## Endpoints
| Method | Endpoint | Description |
|--------|----------|--------------|
| GET | /api/products | Fetch all products |
| GET | /api/products/:id | Fetch a single product |
| POST | /api/products | Create a new product |
| PUT | /api/products/:id | Update an existing product |
| DELETE | /api/products/:id | Delete a product |

## How to run
npm install
node server.js

Server runs on [http://localhost:3000](http://localhost:3000/api/products)

## Testing
Tested using Postman for all CRUD operations.
